# Homebrew Tap

Homebrew formulae for tools by [@drewburchfield](https://github.com/drewburchfield).

## Installation

```bash
brew tap drewburchfield/tap
```

## Available Formulae

### clings

A feature-rich CLI for Things 3 on macOS.

```bash
brew install clings
```

See [drewburchfield/clings](https://github.com/drewburchfield/clings) for details.

### paperfeed

Scan from an AirScan (eSCL) printer's document feeder to PDF.

```bash
brew install drewburchfield/tap/paperfeed
```

See [drewburchfield/paperfeed](https://github.com/drewburchfield/paperfeed) for details.

### churnpaths

Keep one list of regenerable folders (caches, dependencies, build output) and apply it to Spotlight, Time Machine and Backblaze exclusions.

```bash
brew install drewburchfield/tap/churnpaths
```

Built from [drewburchfield/churnpaths](https://github.com/drewburchfield/churnpaths), a fork of [phillco/churnpaths](https://github.com/phillco/churnpaths).
